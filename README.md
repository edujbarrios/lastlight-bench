# LastLight Bench

Reproducible quality and efficiency evaluation for [LastLight](https://github.com/edujbarrios/lastlight). The benchmark runner, synthetic field-operations corpus, evaluation labels, reports, and CI gates live in this repository.

> **Synthetic-data notice:** ChatGPT invented the entire benchmark corpus and every query. It simulates the structure and content of a realistic municipal emergency-operations document set, but it is not authoritative operational, medical, public-health, electrical, or food-safety guidance.

The complete methodology and measured baselines are added in the reporting change set.
